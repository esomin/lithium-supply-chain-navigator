# LLM 프롬프트 누출(Prompt Leaking) 방지 및 엔터프라이즈 응답 튜닝 보고서

## 1. 개요 (Overview)
본 문서는 RAG 기반 LLM 응답 생성 시 시스템 프롬프트에 정의된 페르소나 지시문이 사용자 응답 첫 문장에 그대로 노출되는 **프롬프트 누출(Prompt Leaking) 및 메타 서두(Meta-announcement) 안티패턴**의 원인을 분석하고, 이를 상용 엔터프라이즈 표준 스타일로 개선한 과정을 기록한 기술 보고서입니다.

---

## 2. 문제 현상 및 원인 분석 (Problem & Root Cause)

### 2.1 문제 현상
* LLM 응답 생성 시 첫머리에 다음과 같은 장황하고 기계적인 메타 선언이 반복 노출됨:
  > *"글로벌 리튬 시장의 최고 분석가로서, 리튬 소비 패턴에 대한 질문에 명쾌하게 답변드리겠습니다."*

### 2.2 근본 원인 (Root Causes)

```
[원인 1: 강한 역할 주입형 서두 지시문]
프롬프트: "당신은 글로벌 배터리 및 핵심 광물 시장 최고 분석가입니다."
                       ↓
모델이 역할을 내면화(Internalize)하지 못하고, 답변 서두의 인사/선언 템플릿으로 오인하여 그대로 복사 출력

[원인 2: 부정적 제약 조건(Negative Constraints) 부재]
"첫 문장에서 자기소개나 역할 선언을 하지 마라"는 명시적 제약 조건이 누락됨

[원인 3: UX 및 토큰 비효율]
불필요한 인사말과 정체성 선언으로 인해 핵심 팩트/결론으로의 진입이 늦어지고 토큰이 낭비됨
```

---

## 3. 해결 방안 (Solution Architecture)

### 3.1 톤앤매너 전환: 역할 주입 ➔ 출력 제약 중심 (Constraint-based Prompting)
페르소나는 답변의 **전문 용어 선택, 분석 깊이, 톤앤매너**에만 간접적으로 영향을 미치도록 통제하고, 실제 발화에서는 스스로를 수식하는 문구를 엄격히 배제합니다.

```
[개선 전 (안티패턴)]
"당신은 글로벌 배터리 최고 분석가입니다. ~에 대해 설명하세요."
      ➔ "글로벌 배터리 최고 분석가로서 리튬 소비에 대해 설명드리겠습니다..." (누출)

[개선 후 (엔터프라이즈 권장)]
"## Role & Instructions
배터리 시장 분석 어시스턴트로서 답변을 작성하세요.
## Negative Constraints
'분석가로서', '설명해 드리겠습니다'와 같은 자기소개 없이 첫 문장부터 즉시 핵심 결론과 데이터로 시작하세요."
      ➔ "글로벌 리튬 소비량 중 배터리 부문이 차지하는 비중은 약 87%로..." (직접 진입)
```

## 4. 세부 적용 내용

### 4.1 의도별 시스템 프롬프트 개선 (`ai-insights-service.ts`)

| 질문 의도 (Intent) | 적용된 출력 제약 지침 (Negative Constraint) |
| :--- | :--- |
| **`GENERAL_MARKET`** (시장 통계) | `"분석가로서", "설명해 드리겠습니다"와 같은 자기소개나 불필요한 메타 서두 없이, 첫 문장부터 즉시 핵심 결론과 정량적 데이터로 시작하세요.` |
| **`GRAPH_TOPOLOGY`** (시설 경로) | `서두의 자기소개나 인사말 없이, 첫 문장부터 즉시 출발 광산(Mine) → 중간 제련소(Refinery) → 도착 공장(Factory)의 구체적인 연결 경로로 시작하세요.` |
| **`REGULATION_POLICY`** (규제 판정) | `역할 선언이나 장황한 서두 없이, 첫 문장부터 질문에 대한 규제 적격성 및 위험도 판정 결과로 즉시 진입하세요.` |

## 5. 개선 결과 비교

| 구분 | 개선 전 (Prompt Leaking 발생) | 개선 후 (Direct Entry 적용) |
| :--- | :--- | :--- |
| **첫 문장 시작** | *"글로벌 리튬 시장의 최고 분석가로서, 리튬 소비 패턴에 대한 질문에 명쾌하게 답변드리겠습니다."* | *"글로벌 리튬 소비량 중 배터리가 차지하는 비중은 약 87%이며, 전기차 및 ESS 시장의 확대로 지배력이 지속 강화되고 있습니다."* |
| **응답 성격** | 메타 선언으로 시작하는 기계적 챗봇 느낌 | 첫 줄부터 핵심 데이터가 등장하는 전문 엔터프라이즈 리포트 |
| **토큰 효율** | 서두 인사말로 불필요한 50~100 토큰 낭비 | 팩트 중심 구성으로 토큰 효율 최적화 |

---
